# ophix-lang-de-creds

> Deutsches Übersetzungspaket für ophix-creds.

German translation pack for [ophix-creds](https://ophix.io).

## Install

```bash
pip install ophix-lang-de-creds
```

Then set `LANGUAGE_CODE = "de"` in your server `.env`.

## What is translated

- Admin UI strings: app name, inline labels, column headers, fieldset titles
- Help text strings from `ophix-server-base` (ClientArtifactBase fields)
- Documentation pages: credentials guide, legacy upgrade guide
